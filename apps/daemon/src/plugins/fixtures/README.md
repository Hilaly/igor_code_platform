# Плагины-фикстуры

Настоящие плагины размером с тест: супервизор поднимает их так же, как любой другой плагин, — через
манифест, воркер и SDK. Проверять супервизор на подделке бессмысленно, потому что проверяется как раз
стык с чужим кодом.

Из проверки типов платформы эта папка исключена намеренно: код плагина живёт по правилам плагина
(`--experimental-transform-types`, [docs/toolchain.md](../../../../docs/toolchain.md)), и `typescripty` существует ровно затем, чтобы это
подтверждать.
