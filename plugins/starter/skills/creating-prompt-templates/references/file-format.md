# Формат prompt templates

Шаблон prompt — плоский Markdown-файл `commands/<name>.md`. В отличие от `SKILL.md`, он не является
файловым скилом и не получает отдельную директорию с соседними ресурсами.

## Корни и приоритет

| Корень                          | Область   |
| ------------------------------- | --------- |
| `<data-directory>/commands`     | `user`    |
| `<project>/.sovereign/commands` | `project` |

Обход не рекурсивный: читаются только Markdown-файлы непосредственно в корне. При одинаковом имени
проектный файл перекрывает пользовательский. Шаблоны плагин не объявляет: строка плагина в каталоге
`/` — это вклад `command` в место `core.session.slash`; его точный browser-контракт описан в скиле
`starter.plugin-frontend`.

## Файл

Имя файла без `.md` становится именем команды. Frontmatter необязателен. Поддерживается строковое
поле `description`; если его нет, каталог использует первую непустую строку тела. Тело после
frontmatter — сообщение, которое получает модель.

Имена `compact`, `fork`, `rename` и `archive` принадлежат командам ядра и не становятся шаблонами.
Они не должны молча подменять встроенные операции сессии.

## Аргументы

Аргументы вводятся человеком одной строкой. Runtime разбирает строку с теми же правилами кавычек,
что и последующую подстановку. В теле доступны:

| Placeholder        | Значение                             |
| ------------------ | ------------------------------------ |
| `$1`, `$2`         | отдельный позиционный аргумент       |
| `$@`, `$ARGUMENTS` | все аргументы                        |
| `${@:N}`           | все аргументы начиная с позиции `N`  |
| `${@:N:L}`         | `L` аргументов начиная с позиции `N` |

Пример:

```markdown
---
description: Создать план для области
---

Составь план для области `$1` с ограничениями: $ARGUMENTS.
```

Если аргумент может содержать пробелы, человек передаёт его в кавычках. Шаблон не должен требовать
от браузера собственного парсера аргументов.

## Проверка

1. Создай файл в правильном корне и запроси каталог команд сессии.
2. Убедись, что имя, description и scope приехали ожидаемыми.
3. Повтори с одноимённым файлом в другом корне и проверь, что project перекрывает user.
4. Запусти шаблон с пустой строкой, несколькими аргументами и аргументом в кавычках.
5. Проверь, что модель получила подставленный текст и что запись лежит в обычном дереве сессии.

## Граница со скилами

`SKILL.md` содержит reusable instructions и попадает в каталог `<available_skills>`. Prompt template
содержит один human-authored prompt и появляется только в каталоге `/` сессии. Не называй один ресурс
другим и не помещай шаблон в `<project>/.sovereign/skills`.
