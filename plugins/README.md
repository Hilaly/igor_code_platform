# Встроенные плагины

Корень встроенного источника ([docs/repository-structure.md](../docs/repository-structure.md)):
папка на плагин, манифест — поле `sovereign` в его `package.json`
([docs/plugins.md](../docs/plugins.md)). Встроенный плагин включён по умолчанию и перекрывается
одноимённым из директории данных.

Плагины здесь — такие же пакеты воркспейса, как в `packages/`: они перечислены в
`pnpm-workspace.yaml`, и без этого `@sovereign/sdk` в их папке не резолвится.

| Плагин       | Что даёт                                                           |
| ------------ | ------------------------------------------------------------------ |
| `base-agent` | агент по умолчанию: инструкции и весь собранный набор инструментов |

Агент из коробки — это вклад плагина, а не встроенная в ядро сущность
([docs/architecture.md](../docs/architecture.md)): выключается он тем же переключателем, что и
любой другой, а заменяется одноимённым плагином из директории данных.
