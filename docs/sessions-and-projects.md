# Проекты и сессии

Как устроена работа, ради которой платформа существует: где запускается агент и что можно сделать
с запущенной сессией. Предметная область — в [vision.md](vision.md), возможности чужого рантайма —
в [agent-runtime-contract.md](agent-runtime-contract.md).

## Проект

Проект — сущность первого класса ([ADR-0045](adr/0045-projects-are-first-class-with-an-ephemeral-default.md)).

- Проект — это папка на машине плюс запись платформы о ней. Сначала проект создаётся, потом в нём
  запускаются агенты; запуск «просто в папке», минуя проект, платформа не предоставляет.
- Папка не обязана быть репозиторием и не обязана существовать на момент создания проекта.
- **Эфемерный проект** — папка `work` внутри директории данных. Он есть всегда, создаётся при
  первом запуске и не удаляется: это проект по умолчанию для работы, не привязанной к диску.
- Удаление проекта в платформе не удаляет папку пользователя.
- Папка проекта — это та самая рабочая директория, из которой берётся третий, самый частный
  источник плагинов ([vision.md](vision.md), «Схема плагинов»).

## Сессия

Сессия принадлежит проекту и живёт в ядре ([ADR-0010](adr/0010-core-owns-agent-sessions.md)):
выгрузка плагина, который её создал, сессию не останавливает.

При запуске сессии задаются проект и агент. Модель и уровень ризонинга можно переопределить —
и на старте, и на каждом турне; в дереве сессии это отдельные записи, поэтому переопределение
восстанавливается при перечитывании сессии.

## Что можно делать с сессией

Поверхность API — вся поверхность рантайма плюс архив
([ADR-0046](adr/0046-session-api-covers-the-full-runtime-surface-plus-archive.md)). Возможность,
которую мы не отдали наружу, недоступна и плагинам, то есть её нельзя добавить, не меняя ядро.

| Группа            | Возможности                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------- |
| Жизненный цикл    | создать, продолжить, список, форк от произвольной записи, архив, разархив, удалить          |
| Ход работы        | запустить турн, стиринг, догоняющее сообщение, сообщение к следующему турну, прерывание     |
| Настройки на ходу | модель, уровень ризонинга, набор инструментов и активный поднабор, скилы и шаблоны промптов |
| Контекст          | компакция, навигация по дереву с суммаризацией ветки, дописать сообщение в сессию           |
| Чтение            | дерево записей и ветка, метки, имя сессии, статистика токенов и стоимости                   |

Стиринг, форк, архив и разархив владелец продукта назвал обязательными. Архив — единственное в
этом списке, чего в рантайме нет; остальное берётся из него.

## Открытые вопросы

- Что делает архивирование с активной сессией: запрещено, ждём простоя или прерываем турн.
- Что происходит с сессиями, когда папка проекта исчезла с диска.
- Может ли на одну папку указывать больше одного проекта.
