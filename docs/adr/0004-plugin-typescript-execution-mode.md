# ADR-0004: Run plugin sources with Node's built-in type transform

- **Статус:** Accepted
- **Дата:** 2026-07-26

## Контекст

Плагин — папка с исходниками на TypeScript; компилирует их сам демон в рантайме.
Рантайм — Node.js 24 ([ADR-0002](0002-nodejs-lts-as-runtime.md)), у него два встроенных режима
исполнения TypeScript, оба проверены запуском (см. [runtime-checks.md](../runtime-checks.md),
проверки 1–4):

- по умолчанию — стирание типов; `enum`, `namespace` и parameter properties падают с
  `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`;
- `--experimental-transform-types` — исполняется всё, транспайлер внутри Node.

Существенно, что ограничение бьёт не по нам, а по внешним авторам плагинов: это они получат
ошибку на конструкции, которая в любом другом TypeScript-проекте работает. Объяснять постороннему
человеку, что у нас «TypeScript не совсем TypeScript», — плохая цена за отказ от одного флага.

Проверка 4 показала, что флаг ставится точечно на воркер через `execArgv`, а хост-процесс
остаётся без него.

## Решение

Воркеры плагинов запускаются с `--experimental-transform-types`. Демон и остальной код
платформы работают без этого флага.

Автор плагина не ограничен в синтаксисе TypeScript.

## Альтернативы

- **Только стирание типов.** Отвергнуто. Экономит один флаг, но переносит цену на авторов
  плагинов — запрет на `enum`, `namespace` и parameter properties, о котором надо предупреждать
  в документации и который всё равно всплывёт как непонятная ошибка.
- **Внешний транспайлер (esbuild, swc) в загрузчике.** Отвергнуто. Даёт полный TypeScript и
  контроль над кешем и source maps, но возвращает нативную зависимость, мешающую упаковке
  приложения, и дублирует транспайлер, который уже есть внутри Node.

## Последствия

- Флаг помечен экспериментальным. При переходе на следующий мажорный Node проверки 3 и 4 из
  [runtime-checks.md](../runtime-checks.md) обязательны до апгрейда.
- Если флаг изменится или исчезнет, замена — внешний транспайлер. Чтобы это осталось правкой в
  одном месте, режим исполнения не должен растекаться за пределы загрузчика плагинов.
- Воркер печатает `ExperimentalWarning`. Логи демона не должны шуметь этим на каждый запуск
  плагина — предупреждение глушится при старте воркера.
- Поведение source maps и стек-трейсов плагинов в этом режиме не проверялось. Проверить до того,
  как плагины начнут писать посторонние: непонятный стек-трейс делает отладку плагина невозможной.
