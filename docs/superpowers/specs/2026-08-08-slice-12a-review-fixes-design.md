# Исправления среза 12a по ревью

## Цель

Закрыть две регрессии записи `config.json`, затем влить актуальный `main` в ветку среза 12a без
потери новой формы конфига, живого таймера демона и восстановленного композера сессии.

## Контракт записи конфига

`PUT /api/config` по-прежнему требует все известные текущей версии поля и валидирует их через
`parseConfigUpdate`. Неизвестные поля допустимы: они могут принадлежать более новой версии
платформы, поэтому исходный объект запроса передаётся хранилищу целиком. Хранилище накладывает его
поверх актуального документа на диске и тем самым сохраняет как неизвестные поля запроса, так и
неизвестные поля, уже находившиеся в файле.

Ответ маршрута содержит известный нормализованный `Config`, который реально действует в текущей
версии. Неизвестные поля остаются файловой совместимостью и не расширяют строгий публичный тип
`Config`.

## Ошибки файловой системы

Чтение документа для последующей записи и сама атомарная запись входят в одну контролируемую
операцию. Невалидный JSON или известные невалидные значения остаются конфликтом с чужой правкой и
дают `refused`/HTTP 409. Системная ошибка чтения или записи становится `failed`/HTTP 500 с именем
файла и исходной причиной; исключение не доходит до общего диспетчера как безымянный `internal
error`.

## Интеграция с `main`

Актуальный `main` вливается обычным merge-коммитом. В конфликте страницы Daemon сохраняются обе
независимые возможности: `ConfigForm` из среза и `DurationTimer` с доступной посекундной подписью из
`main`. В документации объединяется действующий контракт обеих веток. Восстановленный композер
сессии принимается из `main` без изменений.

## Проверка

- Регрессионный HTTP-тест отправляет неизвестный ключ именно в теле `PUT` и проверяет файл.
- Регрессионный тест хранилища делает существующий `config.json` нечитаемым и проверяет
  `WriteOutcome`, а не выброшенное исключение.
- После merge проходят адресные тесты настроек, полный `make check`, `make build` и проверка чистого
  diff.

## Почему так

**Расширить `Config` индексной сигнатурой.** Отвергнуто: неизвестные поля нужны для сохранности
документа, но не являются поддерживаемым контрактом текущей версии и ослабили бы типизацию всех
потребителей.

**Отвергать неизвестные поля тела.** Отвергнуто: это ломает прямую и обратную совместимость
редакторов конфига и противоречит правилу не обеднять документ при записи из интерфейса.

**Возвращать исходное тело целиком.** Отвергнуто: текущий демон применяет только известные поля;
ответ должен описывать применяемый снимок, а не обещать поддержку непрочитанных значений.
