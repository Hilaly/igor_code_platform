# Удаление лишних цветовых схем

## Цель

Сократить встроенный набор цветовых схем до актуальных вариантов и сделать `imperium` единственной
темой по умолчанию. Обратная совместимость со старыми идентификаторами не поддерживается.

## Решение

- Удалить из UI Kit схемы `base`, `neutral`, `obsidian`, `terminal` и `check`.
- Оставить в поставке `imperium`, `nord`, `oled` и `sage`; `imperium` сделать первым в
  `shippedSchemes`.
- Переиспользовать существующий идентификатор `imperium` без переименования.
- В протоколе настроек заменить встроенный fallback и значение по умолчанию с `base` на `imperium`.
- В оболочке заменить fallback схемы с `base` на `imperium`.
- Удалить переводы, экспорты, stories, тестовые ссылки и документацию, описывающие удалённые схемы.
- Не мигрировать старые `preferences.json`: при чтении неизвестный идентификатор остаётся строкой, а
  оболочка применяет `imperium` как fallback.

## Границы

Цветовые значения оставшихся схем и контракт палитры не меняются. Варианты светлый/тёмный, масштаб,
локализация и механизм схем, принесённых плагинами остаются без изменений.

## Проверка

- Тесты протокола подтверждают дефолт `imperium`.
- Тесты UI Kit подтверждают состав `shippedSchemes` и отсутствие удалённых схем.
- Тесты web подтверждают fallback `imperium`.
- Полный UI Kit/web test, typecheck, lint и build проходят на итоговой ветке.

## Почему так

Список схем принадлежит UI Kit, поэтому удаление выполняется в едином источнике `shippedSchemes`,
а не отдельными фильтрами в настройках и оболочке. `imperium` уже является существующей темой и
идентификатором, поэтому переименование только создало бы лишнюю ломку без изменения визуального
решения. Совместимость со старыми темами сознательно отвергнута по требованию владельца продукта.
