# Sovereign

### Одна среда для всей вашей работы с ИИ.

Локальная платформа, где ИИ-агенты работают с вашими данными, сервисами и расписанием — связаны между собой, и каждая деталь перестраивается под вас. Не десять приложений. Одно окно.

---

## Что вы можете сделать

### 🌅 «Собери мне утро»

> Вы просыпаетесь. Агент уже прочитал ночную почту, отделил срочное, достал встречи в календарь и собрал daily brief: что сегодня, что горит, что висит со вчерашнего.

Одна команда — и вы в курсе. Без десяти вкладок, без рутины, без «дай-ка проверю ещё вот это».

### 📧 «Письмо → действие»

> Пришло письмо от клиента. Агент читает, выделяет встречу — она уже в календаре. Action items стали задачами. Черновик ответа готов — вы правите и отправляете.

Почта знает про календарь. Задачи знают про код. Всё связано — потому что всё в одном окне.

### 🔥 «CI упал ночью»

> Webhook от GitHub: упала сборка. Плагин автоматизации ловит событие, стартует агента. Агент читает лог, находит причину, правит код, открывает pull request. Вы просыпаетесь — проблема решена.

Реакция на внешние события — не «получите уведомление», а «агент уже разобрался».

### 🗣️ «Что было на встрече?»

> Записали аудио. Транскрипт готов. Конспект — с ключевыми решениями. Action items ушли в задачи. Follow-up-письмо — в черновики.

От записи до результата — без ручной расшифровки и копирования между программами.

### 🔬 «Исследуй и доложи»

> Ставите вопрос. Агент собирает источники — параллельно, проверяет, связывает утверждения с первоисточниками, убирает дубли. На выходе — отчёт с цитатами и ссылками.

Не «вот что я нашёл за пять минут», а структурированное исследование с проверкой фактов.

### 👥 «Команда агентов»

> Большая задача. Agent-менеджер разбивает её на роли, запускает параллельные subagents с изолированным контекстом, собирает результаты. Вы видите структуру, вмешиваетесь, направляете.

Один агент хорош. Команда агентов с разными ролями, инструментами и моделями — мощнее.

### 📱 «Продолжим в Telegram»

> Разговор начат в браузере, продолжен в Telegram, завершён в Slack. Та же сессия, тот же контекст — другой канал.

Агент живёт не в одном приложении. Он там, где удобно вам.

### 🔄 «Каждое утро в 9:00»

> Расписание запускает workflow: проверить почту, собрать бриф, если есть срочное — уведомить. Повторяемый процесс из событий, условий и действий — без единой строки кода.

Автоматизация — не скрипт, а собранный в интерфейсе процесс.

## Фичи

### 🔥 Хот-релоад всего

Правите плагин — он перезагружается на живую. Демон не глушится, сессии не прерываются, работа не останавливается. Это не удобство — это фундамент архитектуры.

### 🧩 Всё заменяемо

Каждое окно интерфейса, каждый агент, каждый инструмент, каждая цветовая схема — вклад плагина. Перекрыли своим — работает ваше. Выключили — вернулось встроенное. **Ничто не вшито намертво.**

### 🎛️ Полный контроль над агентами

Выбираете модель и уровень ризонинга — на каждый турн.

### 🪝 37 точек перехвата

Плагины могут наблюдать за работой агента, изменять её и отменять. Хук до запроса к модели, хук на вызов инструмента, хук на запись в файл — вмешательство в любой момент.

### 💬 Управление сессиями

Форк от любой точки разговора. Стеринг идущего турна. Компакция контекста. Навигация по дереву с суммаризацией веток. Архив и восстановление. Slash-команды: `/compact`, `/fork`, `/rename`, `/archive`, `/skill:<имя>` — плюс собственные: шаблоны промптов из `commands/*.md` и строки плагинов в каталоге `/`.

### 👥 Субагенты

Агент поручает кусок работы скрытой сессии: своя модель, уровень ризонинга и набор инструментов, изолированный контекст, результат — в родительскую сессию.

### 🖼️ Изображения и файлы проекта

Композер принимает JPEG, PNG, GIF и WebP — файлом, вставкой из буфера или перетаскиванием; байты едут в модель. `@` в начале черновика открывает поиск по файлам проекта, а содержимое читает сам агент.

### ⚡ Параллельные сессии

Десятки одновременно живых разговоров — и запускают их не только люди. Плагин автоматизации стартует агентов по событию, и несколько живых сессий разом — норма.

### 📱 Доступ откуда угодно

Демон хостит веб-интерфейс. Зайдите с компьютера, зайдите с телефона — интерфейс пригоден на узком экране. Ваши агенты доступны с любого устройства.

### 🔒 Локально. Только локально.

Данные, сессии, ключи провайдеров — всё в одной директории на вашем диске. Ничего не уходит в облако. Вы хозяин каждого байта.

Поставили сборку, убрали лишнее, добавили своё. Полный каталог — в [docs/product-plugins.md](docs/product-plugins.md).

## Архитектура

**Микроядро.** Ядро даёт точки расширения — всё остальное приносят плагины. Даже базовый агент — вклад плагина, а не часть ядра.

```
ядро                    плагины
─────────────           ─────────────────────
супервизор плагинов     агенты · инструменты · скилы
шина событий            прикладные вью · интеграции
веб-API + SSE           цветовые схемы · локали
сессии агентов          хуки · маршруты · хранилище
оболочка интерфейса
```

Каждый плагин — отдельный воркер: падение одного не роняет остальные. Сессией владеет ядро: создавший сессию плагин выгрузился — сессия живёт дальше.

Бэкенд запуска агентов — [Pi](https://github.com/earendil-works/pi). Подробности — в [docs/architecture.md](docs/architecture.md).

## Быстрый старт

Нужен **Node.js 24** и **pnpm 11**.

```bash
make install     # установить зависимости
make dev         # поднять демон + веб-интерфейс с хот-релоадом
```

Откройте `http://localhost:5273` — задайте пароль при первом входе, и вы внутри.

```bash
make check       # типы, линтер, формат, тесты
make catalog     # каталог компонентов UI-кита
make build       # продакшн-артефакт — один файл dist/sovereign.js
node dist/sovereign.js   # демон отдаёт веб-интерфейс сам: http://127.0.0.1:8787
```

Подробное руководство — [docs/runbook.md](docs/runbook.md).
